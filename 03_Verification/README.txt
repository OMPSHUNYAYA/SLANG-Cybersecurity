SLANG-CYBERSECURITY — VERIFICATION v1.0.0

Run
---
python -B SLANG_Cybersecurity_Evidence_Verifier_v1_0_0.py --verify

Hash scope
----------
SCIENTIFIC_ARTIFACT_SHA256SUMS_v1_0_0.txt contains hashes only for selected key
scientific/code artifacts:
- structural chronology score implementation;
- machine-readable evidence ledger;
- OpTC and E3 reproduction programs;
- baseline and sensitivity audit program;

Editable files such as README.md, LICENSE, notices, and explanatory text files
are deliberately not included in the scientific-artifact hash manifest.

Scope boundary
--------------
The verifier checks ledger consistency, selected artifact integrity, rights
flags, and absence of bundled PDF source objects. It is not independent
scientific validation and does not prove historical pre-reveal chronology.
